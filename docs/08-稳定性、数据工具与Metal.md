# 1.17：稳定性、数据工具与 Metal

本轮保持原窗口、面板、工具栏和弹窗布局。新增的数据工具通过命令行提供；MBTiles 复用现有打开与拖放入口，分析加速复用 DEM 工具箱。

## 已实现

- 临时读取错误与真实缺片分别缓存，自动过期重试；渲染器同步重试。在线 404/410、目录缺片、ZIP 和 SQLite 均有分类。
- 每份数据独立测量存档，原子写入并保留三代备份；旧合并存档继续兼容读取，不再删除第 31 份以后的数据。
- 关闭时刷新存档，每两秒保存工作区。恢复标签、图层顺序/可见性/透明度、视角、测量与分析图层；离线卷的原记录保留，其他标签继续保存。
- 概览与分析任务取消、并发限制、结果代次校验；切来源或标签不接受旧分析结果。
- ZIP 池默认保留最多 16 份，按活跃路径和行表字节预算淘汰；打开并发最多 2 份。乱序行保留多个目录区间，碎片超预算时合并尾区间。
- ZIP、TIFF、概览共用文件身份，包含 inode、大小与纳秒修改时间。内存压力统一清理各类缓存，严重发热降低并发并暂停预取。
- 图片解码前检查压缩字节、尺寸和像素预算；完全越界的瓦片区间安全返回空结果。
- 按职责拆分 TIFF 元数据缓存、地理参考、渲染请求、画布图层与回归检查文件。
- Instruments 可观察索引、读取/解压、图片解码、TIFF 渲染、概览、图层排列、首张可见瓦片、出图合成与 Metal 计算。

## 数据工具

发布包包含 `tiletools-arm64`，应用包内也有 `Contents/MacOS/tiletools`。输入可为瓦片目录、ZIP 数据集或栅格 MBTiles。

```bash
# 显示归档条目数等信息。
./tiletools-arm64 inspect /path/to/2025.zip

# 抽查 CRC 与图片解码；抽样不能证明整包完整。
./tiletools-arm64 check /path/to/2025.zip --samples 128

# 全量检查，可中断。相同检查点会从下一条记录继续。
./tiletools-arm64 check /path/to/2025.zip --full --checkpoint /path/to/report.json

# 每次只检查 256 条，逐步续查大型归档。
./tiletools-arm64 check /path/to/2025.zip --full --checkpoint /path/to/report.json --max-records 256

# 提取范围与层级，输出必须为尚不存在的目录。
./tiletools-arm64 extract /path/to/2025.zip /path/to/regional \
  --bounds 118.0,25.0,118.2,25.2 --zooms 10:12

# 本地只读服务，Ctrl-C 停止。
./tiletools-arm64 serve /path/to/regional --port 8766
```

提取采用流式 ZIP64，每层一个小包及 manifest，可直接拖进应用。不重写原归档、不全包解压，失败/取消清除本次临时输出。

全量审计逐条校验大小、CRC 和图片解码，最多保留 1,000 条详细失败信息，其余计数。检查点含文件身份；文件变化、其他归档或抽样检查点不能用于续查。`complete: false` 表示尚未检查完。目录和 MBTiles 支持指定范围/层级的覆盖抽查；全量断点审计适用于 ZIP。

MBTiles 支持 PNG/JPEG/WebP，SQLite 只读连接与复用查询，TMS 行号转 XYZ。不支持矢量 PBF。

ZIP/MBTiles 服务通过 `http://127.0.0.1:8766/{z}/{x}/{y}.png` 提供；EPSG:4490 经纬度行按像素纬度转换到标准 Web Mercator XYZ（最近邻采样，输出边长最多 1024），支持 HEAD 与实际图片 MIME。服务只读取请求交叠的瓦片。

## Metal 与移动平台

坡度、两期差异重采样、坡度/差异着色使用 Apple Silicon 的共享内存计算缓冲。自动模式在后台处理至少 100 万样本的坡度与着色时启用 Metal；差异重采样实测收益较小，自动模式保留 CPU（显式 Metal 路径仍可验证）。GPU 不可用、提交失败、参数超出 Float 范围时回退。坐标、测地面积、体积累计保持 Double。

```bash
./Scripts/run-benchmarks.sh --metal
./Scripts/run-benchmarks.sh --zip /path/to/2025.zip
./Scripts/run-benchmarks.sh --zip-stack /path/to/year1.zip /path/to/year2.zip
./Scripts/run-checks.sh
./Scripts/check-platforms.sh
```

iOS/iPadOS 的共享核心和 UIKit 画布使用 ARM64，包含 Metal 与 SQLite 支持。三个 SDK 编译不代表已交付完整 iPhone/iPad 应用：应用入口、触控产品流程、签名与真机交付仍需独立平台项目。

## 本轮验证

2026-10-08，Apple M1 Max，Release / ARM64：

- **790 项自检通过**。覆盖缺片恢复、45 份测量存档、备份恢复、乱序行、比例裁剪、概览取消、CRC 损坏、断点续查、ZIP64 提取、只读 MBTiles 和 Metal 数值一致性，另外校验中间表达式溢出回退及重投影像素南北方向。
- macOS 14、iOS/iPadOS 17 真机、ARM64 模拟器三个 SDK 的共享模块编译通过；发布应用与工具只含 arm64，严格签名检查通过。
- 14 个窗口/面板源文件 SHA-256 与冻结前一致。实际应用截图确认原浮动图层、检查器、工具条和状态栏保留。
- 两个标签跨进程恢复：图层顺序/显示/0.37 透明度、视角、测量及生成坡度图完整往返；影像离线时原会话记录保留。最终应用实测切页取消、显式取消均无旧结果插入。
- 用户提供的 `2025.zip` 为 171,788,867,086 字节、15,938,667 条目、1,176,624,634 字节中央目录、7,064 行。抽查 128 张图片无错误；分两次全量模式各检查 256 条，报告准确续到 512 条、无错误、`complete: false`。**没有检查完 1,593 万条记录**。
- 从实际 ZIP 提取 `118,25,118.2,25.2`、z10–12，共 15 张、365,045 字节、三个 ZIP64 小包；共享数据集读取、覆盖抽查和应用打开通过。实测中断 z18 提取后临时目录清除。
- 实际 EPSG:4490 ZIP 经 HTTP 提供为标准 XYZ，GET 返回 PNG、HEAD 保留长度，服务停止正常。
- 单来源持续浏览 120 秒，合成滚动/拖动/甩动通过；截图之后稳态内存约 168 MiB、文件描述符 45 个。不是长期内存上界。

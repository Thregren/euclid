# 1.15 开发清单

目标：把前两轮讨论里列出的**全部**优化与功能一次做完，重点盯三件事 ——
模块解耦（谁的职责写在哪）、内存安全（不崩、不泄漏、不越界）、性能安全（热路径别退步）。

做法：每一条都「改 → 编译 → 自检」，完成一条划掉一条；全部做完再统一清理、
补自检、更新文档并发版。

## A. 性能优化（低风险，先做）

- [x] A1 铺图重铺时跳过没变的 `layer.frame`
- [x] A2 瓦片网格路径加签名缓存（相机 / 视口没变就不重建）
- [x] A3 视野读数合成一次遍历（原来 `filter` 三遍）
- [x] A4 无障碍层级文本缓存（值没变不写）
- [x] A5 `DateFormatter` 提成共享实例（存档 / 导出路径）
- [x] A6 检查器测量列表惰性化

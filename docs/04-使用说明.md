# 使用说明

## 打开瓦片

应用会自动记住上次打开的目录。其他方式：

- 工具栏「文件夹」按钮、空状态里的「选择文件夹…」，或 ⌘O
- 把文件夹拖到窗口上
- 把文件夹拖到 Dock 图标上（应用已在运行时）
- 侧栏「最近打开」里点选历史目录

选择的目录可以是数据集本身，也可以是装数据集的容器（应用会向下找三层）。
数据集需要形如 `<z>/<x>/<y>.png` 的目录结构，WebODM / ODM 的默认输出即符合。

## 浏览

| 操作 | 效果 |
| --- | --- |
| 鼠标滚轮 | 以指针为锚点缩放 |
| 鼠标中键拖动 | 平移（任何工具下都能用） |
| 鼠标左键拖动 | 平移（浏览工具；测量工具下拖动同样是平移） |
| 触摸板捏合 | 以指针为锚点缩放 |
| 触摸板双指滚动 | 平移（带系统惯性），按住 ⌘ 改为缩放 |
| 触摸板双指双击 / ⌥双击 | 放大 / 缩小 |
| ⌘= / ⌘- | 放大 / 缩小 |
| ⌘0 / ⌘⇧0 | 适配数据范围 / 原始比例 |
| 方向键（+Shift 加速） | 平移 |

## 测量

工具栏中间的分段控件切换工具，快捷键是 V（浏览）、C（点坐标）、D（测距）、A（测面积）、O（画圆），
菜单里对应 ⌘1–⌘5。

**测距**：点击加点，双击或回车结束；⌫ 撤销上一点，Esc 取消整条。
**测面积**：点击加点，超过三点后双击或回车闭合。
**点坐标**：单击直接取点。
**画圆**：先点一下确定圆心，移动指针预览半径，再点一下确定半径；
完成之后拖动「半径点」可以随时改半径，也可以在检查器的「半径」里输入精确数值（单位可选米 / 公里）。

| 辅助操作 | 说明 |
| --- | --- |
| 顶点吸附 | 落点靠近已有顶点（12 px 内）会自动吸附 |
| 拖动顶点 | 按住任意顶点拖动即可微调，草稿和已完成的测量都支持；圆是拖动半径点改半径 |
| Shift | 约束方向为正交或 45° |
| ⌘ | 临时关闭吸附 |

测量结果在右侧检查器里：总长/周长、面积、闭合差、逐段长度与方位角、转角。
点击某条测量可切换是否选中（选中的会显示分段标注），右键可复制或删除。

## 样式

在检查器里选中一条测量后，可以单独调整它自己的外观：

| 控件 | 作用 |
| --- | --- |
| 描边颜色 | 折线、圆周与顶点的颜色 |
| 描边粗细 | 0.5–6 点，方便在密集底图上区分 |
| 填充颜色 | 多边形与圆的填充色 |
| 填充不透明度 | 0–100%，默认 16%，调到 0 就是纯描边 |

「应用到全部」把当前样式套用到所有测量，「恢复默认」回到调色板默认样式。
没有改过颜色的测量会继续跟随调色板与系统深浅色切换；一旦指定颜色就固定下来。

## 坐标

检查器顶部实时显示指针位置的度分秒、十进制度、瓦片编号 `z/x/y`、瓦片内像素与墨卡托米坐标，
可一键复制。展开「跳转到坐标」输入经纬度即可定位。

## 导出

工具栏的导出按钮支持：

- 复制为 GeoJSON / KML / CSV
- 导出为 GeoJSON / KML / CSV 文件
- 导出为 Excel 表格（`.xlsx`），共四张工作表：

| 工作表 | 内容 |
| --- | --- |
| 测量汇总 | 编号、类型、点数、长度/周长、直线距离、面积、半径、圆心经纬度、记录时间 |
| 点坐标 | 每个顶点的经纬度、Web Mercator 东/北坐标、累计长度、本段长度、方位角 |
| 分段明细 | 每段的起点/终点、长度、方位角、方位、转角、累计长度 |
| 说明 | 坐标系、距离与面积算法、圆的计算口径、导出时间 |

GeoJSON 与 KML 使用 WGS84 经纬度（CRS84），可以直接拖进 GIS 软件；圆在几何格式里按
闭合多边形（180 点采样）输出，半径写在属性里。

## 已知限制

- 首次打开「文稿」「桌面」「下载」中的目录时，macOS 会弹一次授权询问。
- 测量结果按数据集目录自动存档（`~/Library/Application Support/Euclid/measurements.json`），
  再次打开同一数据集会自动恢复；要跨机器或交给别人，仍然需要先导出。

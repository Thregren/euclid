# 使用说明

## 打开瓦片

应用会自动记住上次打开的目录。其他方式：

- 工具栏「文件夹」按钮、空状态里的「选择文件夹…」，或 ⌘O
- 把文件夹拖到窗口上
- 把文件夹拖到 Dock 图标上（应用已在运行时）
- 侧栏「最近打开」里点选历史目录

选择的目录可以是数据集本身，也可以是装数据集的容器（应用会向下找三层）。
数据集需要形如 `<z>/<x>/<y>.png` 的目录结构，WebODM / ODM 的默认输出即符合。

## 打开单幅影像（GeoTIFF / TIFF）

⌘⇧O，或把 `.tif` / `.tiff` 文件直接拖进窗口。ODM / WebODM 的 `odm_orthophoto.tif`
不用先切成瓦片，打开就能看、能量、能出图。

- **按地理参考摆放**：读的是文件里的 GeoTIFF 标签（定位点 + 像素尺度 + GeoKey），
  UTM、CGCS2000 的高斯克吕格分带、Web 墨卡托、经纬度都换算到 WGS84，
  因此与在线底图、测量坐标、比例尺严格对齐
- **按需解码**：只解屏幕上需要的那一块，再大的图也不整张进内存；
  档位（分块 / 横条、Deflate / LZW / PackBits / JPEG、8 / 16 位、灰度 / RGB / 调色板 / alpha）
  都按文件里写的来
- **内建概览**：文件里带概览（`gdaladdo` 那种 reduced-resolution 目录，或 COG 的 SubIFD）时，
  缩小会取低分辨率级，翻页很跟手；没有概览的大图，第一次在很低倍数下看会慢一些
- **未配准也能看**：没有地理标签、或者坐标系认不出来（界面上会写明原因）时，
  按「1 像素 = 1 米、中心在原点」摆着看——图能看、能量，但坐标没有地理意义

单幅影像和瓦片数据集一样会出现在侧栏「数据源」里，检查器里能看到像素尺寸、坐标系、
地面分辨率（米/像素或厘米/像素）、压缩方式、文件大小与是否有内建概览。
测量结果同样按文件路径自动存档。

## 浏览

### 从影像生成瓦片

⌘⇧T 打开「从影像生成瓦片」：把一整幅 GeoTIFF / TIFF 切成 `<z>/<x>/<y>.<ext>` 瓦片目录，
生成完可以直接用本程序打开（离线浏览、量测、出图都照常）。

- **尺寸**：512（默认，本地浏览按设备像素 1:1）或 256（通用地图约定）
- **格式**：JPEG（默认，质量 85 可调）或 PNG（无损、保留透明区，体积约为 JPEG 的八倍）
- **层级**：默认取「一个影像像素对一个瓦片像素」那一级往前 3 级
- 已存在的瓦片默认跳过，长任务中断后可以接着跑；纯无数据区不写文件

| 操作 | 效果 |
| --- | --- |
| 鼠标滚轮 | 以指针为锚点缩放 |
| 鼠标中键拖动 | 平移（任何工具下都能用） |
| 鼠标左键拖动 | 平移（浏览工具；测量工具下拖动同样是平移） |
| 触摸板捏合 | 以指针为锚点缩放 |
| 触摸板双指滚动 | 平移（带系统惯性），按住 ⌘ 改为缩放 |
| 触摸板双指双击 / ⌥双击 | 放大 / 缩小 |
| ⌘= / ⌘- | 放大 / 缩小 |
| ⌘0 / ⌘⇧0 | 适配数据范围 / 原始比例 |
| 方向键（+Shift 加速） | 平移 |

## 在线底图

侧栏「底图」里选「在线底图」，再挑一个数据源；工具栏的底图菜单里也能切。
切到在线底图后：

- 地图来自网络，取图走与本地数据集同一套内存缓存与并发闸门，
  平移、缩放、测量、坐标读取、比例尺都照常可用
- 视野安定后会预取外面一圈瓦片（本地走磁盘、在线走网络），再平移时更顺
- 需要密钥的数据源（天地图）在侧栏里填一次 tk，按回车或点「应用」即可；
  密钥只放在内存里，退出程序后需要重填
- 状态栏左下角会显示当前底图与版权归属，检查器的「在线底图」分区里有层级范围与条款提醒
- **叠加对照**：在线底图与本地影像可以同时显示。侧栏「图层」里给两层各配一条不透明度滑杆——
  把「影像不透明度」调到 50% 左右，就能透过正射影像看到底图路网，用来核对配准；
  把「底图不透明度」调低则相反。两层的开关与来源在同一个分区里，检查器的「图层」分区能看到当前状态
- 想只看本地数据：关掉「叠加在线底图」开关

### 坐标基准（底图与影像对不对得上）

底图在哪个基准上，直接决定它和你的正射影像能不能叠在一起：

| 数据源 | 基准 |
| --- | --- |
| 天地图、OpenStreetMap、WebODM 正射影像 | WGS84 / CGCS2000 |
| 高德、腾讯 | GCJ-02（火星坐标，城区偏 100–500 m） |
| 百度 | BD-09 |

在侧栏「底图」里把「坐标基准」选成对应的一档，在线底图就会按该基准整体平移，
叠加时与 WGS84 的正射影像对齐。切换后状态栏会给出偏移的方向与量级
（例如「GCJ-02 相对 WGS84 向东 492 m、向北 360 m」）：量级明显不对、或者方向反了，
说明基准选错了。检查器的「在线底图」分区里同样能看到当前基准与对齐偏移。

坐标读数、测量结果与导出始终按 WGS84 输出，不受这个设置影响。
离线下载也共用这个基准：按该基准的瓦片网格取编号，落盘清单里会写明基准。

底图与下载面板共用同一套数据源参数：在这里选的源，打开下载面板就是同一个，
反过来说下载面板里改的模板也直接用于在线浏览。

## 下载在线瓦片

工具栏「下载在线瓦片」按钮或 ⌘⇧D 打开面板。用途是把在线底图取到本地，
在没网或不想一直连网时继续看图、量测。

**步骤**

1. **数据源**：选一个预设，或选「自定义模板」自己填 URL 模板。
   - 天地图（影像 / 影像注记 / 矢量）走官方 WMTS 接口，需要填天地图开发者密钥（tk）。
     密钥只放在内存里，退出程序后要重新填。
   - 模板占位符：`{z}` 层级、`{x}` 列、`{y}` 行、`{-y}` TMS 行号、
     `{s}` 子域轮转、`{key}` 密钥。因此 `https://…/{z}/{x}/{y}.png` 这类 XYZ 直连、
     `{z}/{y}/{x}` 这种列行顺序、以及 WMTS KVP 风格（把 `TILEMATRIX={z}&TILEROW={y}&TILECOL={x}` 写进模板）都能用。
   - 模板里带扩展名时会自动用它作为落盘后缀。
2. **区域**：「用当前视图」把当前屏幕范围填进来，也可以按「数据范围」或手输西/南/东/北经纬度。
   「复制范围」把当前范围（`西,南,东,北`）拷到剪贴板，「用剪贴板范围」则反过来读回来，
   便于和别的 GIS 工具对接。
3. **层级与规模**：设最小、最大层级，面板会实时给出预计瓦片数与粗略体积。
   层级每加一级，瓦片数大约翻两番，下载前先看一眼预计数量。
   旁边的「复制瓦片清单」把计划的 `z,x,y` 列表拷到剪贴板。
4. **输出**：选择保存目录（下载完可直接用本程序打开）；可调并发（默认 6 路）与限速（默认 24 次/秒）。
   默认「跳过已存在」——中断后再点一次就开始续下，不会重复取已经有的瓦片。
5. 点「开始下载」。面板顶部显示进度、速度与预计剩余时间，随时可以「停止下载」。
   结束后用「在访达中显示」或「打开这个数据集」查看结果。

**落盘结构**：`<输出目录>/<z>/<x>/<y>.<ext>`（WebODM 同款布局），
另外写入 `source.json` 与 `attribution.txt` 记录来源、范围、层级与使用条款提醒。

**关于数据源授权**：批量下载属于典型的「离线缓存」，各家条款差别很大。
天地图、OpenStreetMap 等预设已在面板里注明各自的限制；Google 地图等明确禁止把瓦片抓取到服务之外保存的源，
本程序不提供预设（需要时可在「自定义模板」里填你有权使用的源）。
请只下载你有权保存的瓦片，并注意别超过对方的配额。

## 测量

工具栏中间的分段控件切换工具，快捷键是 V（浏览）、C（点坐标）、D（测距）、A（测面积）、O（画圆），
菜单里对应 ⌘1–⌘5。

**测距**：点击加点，双击或回车结束；⌫ 撤销上一点，Esc 取消整条。
**测面积**：点击加点，超过三点后双击或回车闭合。
**点坐标**：单击直接取点。
**画圆**：先点一下确定圆心，移动指针预览半径，再点一下确定半径；
完成之后拖动「半径点」可以随时改半径，也可以在检查器的「半径」里输入精确数值（单位可选米 / 公里）。

| 辅助操作 | 说明 |
| --- | --- |
| 顶点吸附 | 落点靠近已有顶点（12 px 内）会自动吸附 |
| 拖动顶点 | 按住任意顶点拖动即可微调，草稿和已完成的测量都支持；圆是拖动半径点改半径 |
| Shift | 约束方向为正交或 45° |
| ⌘ | 临时关闭吸附 |

测量结果在右侧检查器里：总长/周长、面积、闭合差、逐段长度与方位角、转角。
点击某条测量可切换是否选中（选中的会显示分段标注），右键可复制或删除。

## 样式

在检查器里选中一条测量后，可以单独调整它自己的外观：

| 控件 | 作用 |
| --- | --- |
| 描边颜色 | 折线、圆周与顶点的颜色 |
| 描边粗细 | 0.5–6 点，方便在密集底图上区分 |
| 填充颜色 | 多边形与圆的填充色 |
| 填充不透明度 | 0–100%，默认 16%，调到 0 就是纯描边 |

「应用到全部」把当前样式套用到所有测量，「恢复默认」回到调色板默认样式。
没有改过颜色的测量会继续跟随调色板与系统深浅色切换；一旦指定颜色就固定下来。

## 坐标

检查器顶部实时显示指针位置的度分秒、十进制度、瓦片编号 `z/x/y`、瓦片内像素与墨卡托米坐标，
可一键复制。展开「跳转到坐标」输入经纬度即可定位。

## 导出

### 出图（当前视图存成图片）

| 操作 | 快捷键 | 效果 |
| --- | --- | --- |
| 导出当前视图为图片… | ⌘⇧E | 打开保存面板存成 PNG |
| 复制当前视图到剪贴板 | ⌘⇧C | 直接粘到聊天窗口或文档里 |

成图就是画布本身——瓦片、测量标注与读数都在——下面多一条信息栏，写明数据源、中心坐标、
层级与比例尺，这样单独一张图也能看懂出处。保存面板里有一个「包含测量标注」勾选项，
取消它就能导出一张干净的地图（画面里的瓦片网格永远不会进成图，那是排查用的）。

### 测量结果

工具栏的导出按钮支持：

- 复制为 GeoJSON / KML / CSV
- 导出为 GeoJSON / KML / CSV 文件
- 导出为 Excel 表格（`.xlsx`），共四张工作表：

| 工作表 | 内容 |
| --- | --- |
| 测量汇总 | 编号、类型、点数、长度/周长、直线距离、面积、半径、圆心经纬度、记录时间 |
| 点坐标 | 每个顶点的经纬度、Web Mercator 东/北坐标、累计长度、本段长度、方位角 |
| 分段明细 | 每段的起点/终点、长度、方位角、方位、转角、累计长度 |
| 说明 | 坐标系、距离与面积算法、圆的计算口径、导出时间 |

GeoJSON 与 KML 使用 WGS84 经纬度（CRS84），可以直接拖进 GIS 软件；圆在几何格式里按
闭合多边形（180 点采样）输出，半径写在属性里。

## 已知限制

- 首次打开「文稿」「桌面」「下载」中的目录时，macOS 会弹一次授权询问。
- 测量结果按数据集目录自动存档（`~/Library/Application Support/Euclid/measurements.json`），
  再次打开同一数据集会自动恢复；要跨机器或交给别人，仍然需要先导出。

# 开发进度

## M1 · 工程骨架与瓦片渲染 ✅

- SwiftPM 多目标工程：`TileKit`（核心库）、`EuclidApp`（应用）、`TileKitCheck`（自检）
- 投影：Web Mercator ↔ WGS84，瓦片编号与像素坐标三向互转，往返误差 < 1e-9
- 数据层：目录型数据源，`<z>/<x>/<y>` 与 `<z>/<y>/<x>` 自动嗅探，XYZ / TMS 行号可配，
  跟随符号链接，不做全量扫描；LRU 内存缓存 + 并发解码闸门 + 缺片负缓存
- 渲染：Core Animation 图层金字塔，每瓦片一个 CALayer，平移缩放只改 transform
- 交互：拖动平移、双指滚动平移、滚轮/⌘滚动/捏合缩放（锚点跟随指针）、双击放大、⌥双击缩小、
  方向键平移、⌘= / ⌘- / ⌘0 / ⌘⇧0
- 界面：三栏结构（侧栏 + 画布 + 检查器）、工具栏、底部状态栏、比例尺、缩放控件、空状态

## M2 · 坐标与视图信息 ✅

- 指针坐标：度分秒、十进制度、瓦片 `z/x/y`、瓦片内像素、墨卡托米坐标
- 一键复制坐标；输入经纬度跳转到指定位置
- 检查器实时显示中心坐标、缩放层级、分辨率、视口瓦片数、已缓存与缺片数
- 拖放打开：把文件夹拖到窗口上即可打开；侧栏记录最近打开的目录

## M3 · 测距 ✅

- 折线测距：点击加点、双击/回车结束、⌫ 撤销、Esc 取消
- WGS84 椭球 Vincenty 反向公式，每段给出长度、方位角、罗盘方位与转角，另有总长与起终点直线距离
- 顶点吸附（12 px 内吸附到已有顶点）、按住 Shift 约束水平/垂直/45°、按住 ⌘ 关闭吸附
- 任意顶点可拖动微调（草稿与已完成测量都支持）

## M4 · 测面积与导出 ✅

- 多边形测面积：周长、测地面积、闭合差，支持顶点拖动
- 点坐标工具：单击取点并读取坐标
- 导出 GeoJSON / KML / CSV，或直接复制到剪贴板
- 多条测量并存，各自配色，可选中查看分段明细、单独删除或全部清除

- 应用图标（ICNS）、Info.plist 元数据、ad-hoc 签名打包

## M6 · 画圆、样式与 Excel 导出 ✅

- **浏览手势**：鼠标滚轮缩放，鼠标中键拖动平移（任何工具下都可用），左键拖动与触摸板双指滚动平移，
  触摸板捏合缩放；滚动量的缩放指数收敛到一个命名常量，便于调手感
- **画圆**：`MeasurementKind.circle` + `MapTool.circle`（O / ⌘5）。点圆心、再点一次定半径，
  拖「半径点」随时改半径，或在检查器里输入精确半径（米 / 公里）
  - 圆心与半径点存为两个顶点，半径取两者的 WGS84 测地距离
  - 新增 Vincenty 直接公式 `Geodesy.destination(from:initialBearing:distance:)`，
    圆周按 360 点测地采样，周长与面积都按同一组采样环计算，画出来的和算出来的一致
  - GeoJSON / KML 导出为 180 点闭合多边形，半径写进属性
- **逐条样式**：`MeasurementStyle`（描边颜色、描边粗细、填充颜色、填充不透明度）
  - 颜色是可选的覆盖值，没改过就继续用调色板语义色（仍随深浅色切换），改过就固定为 sRGB 分量
  - 检查器里用 ColorPicker + 滑块编辑，可「应用到全部」或「恢复默认」
  - 连续拖动滑块 / 连着调色只记一次撤销（撤销点合并窗口 1.5 s）
  - 旧存档缺 `style` 字段时手工解码回落默认样式
- **Excel 导出**：零依赖生成 `.xlsx`（`XLSX.swift`）
  - 自带一个只做「存储」的 ZIP 打包器与 CRC32，OOXML 允许不压缩存放成员，省掉 deflate 实现
  - 四张表：测量汇总、点坐标（含 Web Mercator 东/北坐标）、分段明细、说明
  - 自带 `ZIP.parse` 反解器，自检里逐条校验 CRC，保证产出的确是能被 Excel 打开的包

## M6.1 · 缺陷修复 ✅

两个都是「换层级」引起的渲染问题，靠 `EUCLID_TRACE_VIEW=1` 打出的每帧数字定位：

- **切换缩放层级后瓦片整屏消失**：渲染层维护了一个「请求过就不再请求」的集合，
  而换层级会把不再需要的图层整批移除；回到该层级时图层是新建的、图片却不会再取，
  只剩空的占位图层，整屏看起来就是「瓦片都没了」。
  现在判断依据改为「这一帧还缺图 + 没有在途请求 + 不是已确认缺片」，
  已取过的图片由 `TileProvider` 的内存缓存直接命中，不再有这道永久门槛
- **缩放到上下限后继续滚动会平移视图**：`zoomed(by:anchorViewPoint:)` 先按未夹取的层级
  计算锚点补偿、再 `clamped` 只修正比例尺，于是到达极限后每一格滚动都变成一次平移，
  几步就把影像推出画面（实测每步中心漂移约 1.3e-4 世界单位，而数据集只有 1.8e-4 宽）。
  现在把目标层级先夹到范围内再算补偿，层级不变时直接返回原相机

附带改进：取图队列在有并发额度空出时自动补跑，不再依赖用户继续操作。
自检相应新增 13 项（151 项总计），覆盖缩放极限处的连续缩放与锚点补偿。

## 质量保障

- `TileKitCheck` 共 151 项检查：投影往返、瓦片编号对照真实数据集、相机变换与锚点不变性、
  Vincenty 标准算例与直接/反向互逆、圆的周长与面积对照 `2πr` / `πr²`、样式编解码与回落、
  Excel 包的 ZIP 结构自校验、边界与异常输入、导出格式、真实数据集嗅探
- 构建产物经真机启动截图核对（瓦片渲染、测量标注、比例尺、检查器数据）

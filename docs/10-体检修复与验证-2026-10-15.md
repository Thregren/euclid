## 大型 ZIP 与 Metal 实测

测试原文件 `/path/to/imagery/2025/2025.zip`，大小 171,788,867,086 字节；只读访问，未解压或修改。包含 15,938,667 条记录、1,176,624,634 字节中央目录和 7,064 个行前缀。

最终 Release 复测使用独立空索引目录，操作系统缓存未清理，因此不是冷盘基准：重新建立索引 693.061 ms，随即重开 18.470 ms；跨行查找 p50 2.689 ms、p95 4.051 ms；125/125 张抽样瓦片解码成功，2,107,086 字节，批次 38.527 ms。抽样不等于全量归档校验。

Metal 采用预热管线，取多次中位数，包含缓冲准备、提交、完成与回读。2048 × 2048 结果如下，属于计算基准，不代表整帧或整个分析流程的耗时。

| 计算 | CPU | Metal |
| --- | ---: | ---: |
| 坡度 | 63.626 ms | 2.527 ms |
| 着色 | 42.409 ms | 2.148 ms |
| 数组差值 | 13.342 ms | 2.667 ms |

小规模差值并非总在 GPU 上更快；自动路径保留 CPU 选择。地理坐标、地面度量与工程量保持 Double。Metal 同步 API 仍等待命令完成，本轮未改为完整异步 GPU 流水线。
